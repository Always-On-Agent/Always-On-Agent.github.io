ALWAYS-ON / OPEN PROTOTYPE

A world that remembers.

A prescribed village, a borrowed book, and a pair of glasses. Explore the library and café, read visible evidence, confirm an item transfer, and inspect the Sensing–Memory–Action trace.

Scenario and glasses interface

The Always-On Agent team authored this village layout, scripted interaction, bilingual interface, and website integration. This prototype runs a single-player server inside the browser. There is no account, remote game server, camera, microphone, or live AI model. Scene observations and assistant decisions are scripted.

Preferences and the event journal stay in browser storage. Each reload starts a fresh book-return episode while retaining prior context; old notice information remains unverified until observed again. The return box removes the tagged book from the player's inventory and records a receipt in the current session. It does not use a persistent chest inventory.
